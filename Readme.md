# 📌 8086 Microprocessors

## 📖 Overview
This repository contains Assembly Language programs and study materials related to the **Intel 8086 Microprocessor**.  
It is created for academic learning, laboratory experiments, and practice of low-level programming.

The Intel 8086 is a 16-bit microprocessor and the foundation of the x86 architecture.

---

## 🧠 Topics Covered

- 8086 Architecture
- Register Organization
- Instruction Set
- Addressing Modes
- Arithmetic and Logical Instructions
- Looping and Branching
- String Operations
- Stack Operations
- Interrupts
- Flag Register Operations

---

## 🛠️ Tools Used

- TASM (Turbo Assembler)
---

## 🎯 Purpose

This repository is created for:
- Academic reference
- Lab experiments
- Practice of 8086 Assembly Language
- Strengthening low-level programming concepts
